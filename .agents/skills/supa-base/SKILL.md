# Supabase Schema 規格書

依使用者提供的 SQL 或指定的 Schema 檔案，整理給不懂程式的人看的規格書，使用繁體中文。只有指定專案資料表而未提供定義時，才搜尋專案中的 Schema 或 migration。資訊不足或版本不明時標示「未確認」，不自行補造欄位。

## 判讀規則

- 按資料表欄位順序列出，保留實際英文名稱，中文名稱採容易理解的日常用語。
- 「必填」依資料表是否允許空值判斷：NOT NULL 或主鍵為「是」，允許 NULL 為「否」。有預設值不代表可存空值，外鍵也不代表必填。
- 系統自動產生的必填欄位，標示「是（系統自動產生）」或「是（系統自動記錄）」。一般預設值可標示「是（預設為否）」等短句。可空且有預設值仍標示「否」，必要時括號說明預設值。
- auth.uid() 表示預設為目前登入使用者，不保證未登入時有值。
- 資料型態使用中文：文字類為「文字」、UUID 為「唯一識別碼」、整數類為「整數」、小數類為「數字」、布林值為「是／否」、date 為「日期」、timestamp / timestamptz 為「日期與時間」、time 為「時間」、JSON 為「資料組合」、陣列為「清單」。其他型態依用途翻成易懂中文，不確定時標示「未確認」。
- 若附有 ALTER TABLE，套用相關欄位及限制變更。索引、外鍵與限制名稱不列為欄位。

## 輸出格式

標題為「資料表中文名稱（資料表英文名稱）簡易規格書」，接著只列四欄：

| 欄位英文名稱 | 欄位中文名稱 | 必填 | 資料型態 |
|---|---|---|---|
| title | 活動標題 | 是 | 文字 |
| created_at | 建立時間 | 是（系統自動記錄） | 日期與時間 |

若有影響填寫的明確限制，可在表格後用一句白話補充，例如「結束時間必須晚於開始時間」。多個資料表分開呈現。

除非使用者另有要求，不增加技術說明、索引細節、SQL、API 規格或其他表格欄位；直接在對話顯示，不另建文件。不執行 SQL、不連線修改資料庫，也不為產出規格書讀取 .env 或憑證。
